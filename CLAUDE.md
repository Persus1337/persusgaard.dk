# persusgaard.dk

Statisk hjemmeside for Per Susgaard, hostet på GitHub Pages med custom domain `persusgaard.dk` (se `CNAME`). DNS ligger hos simply.com.

## Arbejdsgang

- Når Per har godkendt en ændring, committer og pusher du den til `main` uden at spørge igen. GitHub Pages udgiver automatisk fra `main`.
- Lav ikke commits eller pushes af ændringer, der ikke er godkendt.
- Skriv korte commit-beskeder, der forklarer hvad og hvorfor.
- Repoet er public: commit aldrig private filer, kodeord eller andre hemmeligheder.

## Struktur

- `index.html` – forsiden (ren HTML/CSS, ingen build-step)
- `CNAME` – custom domain til GitHub Pages; må ikke slettes
